# План развития HelperBot

## Готово

- Ежедневное напоминание о дневнике в 18:00 по времени Барнаула.
- Фразы из раздела «Более живые варианты» в `DIARY_REMINDERS.md`.
- Ручные тесты утреннего дайджеста и вечернего сообщения для администратора.
- Кнопка быстрого перехода из вечернего напоминания в дневник.

## Следующий этап

### Weekly review

- Раз в неделю автоматически собирать записи дневника за прошедшую неделю.
- С помощью AI готовить короткий обзор: что удалось сделать, главные события и возможные незавершённые дела.
- Присылать обзор пользователю по расписанию.
- Добавить администратору кнопку ручного тестирования weekly review.
- Предусмотреть понятное сообщение для недели, в которой записей не было.

Перед реализацией нужно определить день недели, время отправки и формат итогового сообщения.

## Позже

### Распознавание голосовых сообщений

- Принимать голосовое сообщение от пользователя и скачивать аудиофайл из Telegram.
- Распознавать русскую речь через облачный speech-to-text API или локальную модель наподобие Whisper.
- Показывать пользователю распознанный текст до сохранения.
- Добавить действия `Сохранить`, `Исправить` и `Отмена`.
- Сохранять запись в дневник только после подтверждения пользователя.
- Продумать ограничения по длительности, обработку ошибок, стоимость облачного API и удаление временных аудиофайлов.

Предпочтительный первый вариант — облачное распознавание с обязательным подтверждением текста. Telegram Bot API не отдаёт ботам готовую транскрипцию голосового сообщения.

### Другие идеи

- Рассмотреть остальные вопросы и короткие формулировки из `DIARY_REMINDERS.md`; пока не включать их в рабочий пул.
- Добавить monthly review с итогами за месяц после проверки weekly review.
